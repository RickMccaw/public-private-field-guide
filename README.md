# The Collapse of the Public–Private Divide

An interactive, single-page classroom reader for Rick McCawley’s investigative field guide on surveillance capitalism, ambient capture, AI fusion, and democratic liberty.

The experience includes full chapter transcripts, photographic field evidence, chapter-level citations, guided response fields, a 16-week course path, and a browser-local PDF response-paper export.

See [OFFLINE_DEVELOPMENT.md](OFFLINE_DEVELOPMENT.md) for setup, content maintenance, and GitHub Pages deployment instructions.
